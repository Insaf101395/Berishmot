# Управление каталогом сайта (админка)

Бот теперь ведёт каталог сайта и отдаёт его по HTTP. Всё крутится в том же
процессе (`app.py` → `main.py`), никаких отдельных сервисов.

## Как это работает
- **`catalog_store.py`** — надёжное хранилище каталога (`storage_data/site/`):
  мягкое удаление (архив), восстановление, журнал изменений, автобэкапы,
  атомарная запись и валидация (битые данные не перезапишут рабочие).
- **`admin.py`** — веб-маршруты:
  - `GET /products.json` — публичный фид активных товаров (его читает сайт).
  - `GET /admin` — веб-панель управления (пароль `ADMIN_PASSWORD`).
- **`admin.html`** — страница админки: таблица товаров с галочками, поиск и
  фильтры, массовые действия, добавление/редактирование, журнал, откат.

## Что умеет админка
- Вкладки **Активные / Скрытые / Архив / Все** со счётчиками.
- **Галочки** + «выбрать всё», плавающая панель массовых действий:
  - 🗑 **В архив** (мягкое удаление, с подтверждением и числом),
  - **Скрыть / Показать**, **Восстановить**,
  - **Сменить категорию** пачкой,
  - **Изменить цену ±%** пачкой,
  - **Удалить навсегда** (только из архива, необратимо, с подтверждением).
- **Поиск** по названию/артикулу и фильтр по категории.
- **Добавить/изменить** товар (название, категория, цена, старая цена, размеры,
  фото-URL, бейдж, наличие, описание).
- **↶ Откат** последнего изменения (из автобэкапа).
- **Журнал изменений** внизу страницы.

## Доступ
1. В `.env` задайте `ADMIN_PASSWORD=...` (без него `/admin` вернёт 503).
2. Откройте `https://<ваш-домен>/admin`, введите пароль. Сессия хранится в
   подписанной cookie (HMAC на `SESSION_SECRET`).

## Как сайт берёт товары
Сайт (`ber`) тянет каталог с `GET https://<ваш-домен>/products.json`.
В `index.html` в блоке загрузки укажите этот адрес вместо локального
`products.json` (или настройте так, чтобы фронт ходил на домен бота). Пока
адрес не настроен, сайт использует встроенный фолбэк.

## Автопополнение из бота
При публикации товара через бота он теперь также добавляется в каталог сайта
(`_add_to_site`): фото уходят на ImgBB (стабильные ссылки), товар появляется на
витрине. Дальше правите/чистите пачками в админке.
